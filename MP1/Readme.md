# 🛌 Wake Up!!

**Author:** Sachidanand VS  
**NetID:** sv69  

---

## 🎮 Game Description

You are dreaming and stuck in a room. You see a msg telling you to wake up. To wake up, try placing the colored box 
on top of the colored Pillar. To blow off stream, you can have a fit by throwing furniture in the room if you want :) Once you finish the puzzle you will free fall to wake up (like in Inception)

🔗 **Itch.io Link:** [Wake Up](https://sachidanand-cs417.itch.io/wake-up)
